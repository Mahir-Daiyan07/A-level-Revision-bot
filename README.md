# A-Level Revision Assistant Bot

An interactive, asynchronous Discord bot designed to help A-Level students structure their revision, manage study time, and improve exam performance.

# Features

 **Dynamic Revision Planning (`/revision-plan`):** Generates structured 3-day high-yield study plans tailored to any input subject (e.g., Further Maths, Physics, Chemistry).
 **Practical Study Tips (`/study-tip`):** Offers actionable, evidence-based revision strategies such as blurting, active recall, and active past paper analysis.
 **Integrated Focus Timer (`/pomodoro`):** Features built-in Pomodoro timers (25 minutes focus, 5 minutes rest) to maintain study momentum.
 **Slash Command Integration:** Built using Discord's modern application command tree (`/`) with clean embed formatting for fast and clear readability.

# Tech Stack & Architecture

- **Language:** Python 3.10+
- **Library:** `discord.py` (v2.0+)
- **Command Handling:** `discord.app_commands` (Slash Commands)
- **Deployment Platform:** Cloud Hosted (Render / Railway)
