# A-Level Revision Bot

A Discord bot built in Python to help A-Level students plan study sessions, get revision tips, and run focus timers. Built for my Level 6 Degree Apprenticeship portfolio.

## Features

* `/revision-plan` - Generates a 3-day study schedule for a specific subject (e.g., Maths, Physics).
* `/study-tip` - Gives practical advice on techniques like active recall and past papers.
* `/pomodoro` - Starts a 25-minute focus timer with a 5-minute break.

## Tech Stack

* Python 3.10+
* `discord.py` (v2.0+)
* Hosted on Render

## Project Structure

* `bot.py` - Main bot code and slash commands
* `requirements.txt` - Python dependencies
* `README.md` - Project documentation
